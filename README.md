# forfun

## Edgar Portfolio Сайт

Готовый одностраничный сайт для презентации инженера Эдгара находится в каталоге [`site`](site).

### Как запустить

Откройте `site/index.html` в браузере или поднимите простой веб-сервер:

```bash
cd site
python -m http.server 8080
```

После запуска страница будет доступна на `http://localhost:8080`.
