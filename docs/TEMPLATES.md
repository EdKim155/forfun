# Работа с шаблонами промптов

## Формат шаблона

Каждый шаблон хранится в таблице `Template` и содержит:

- `title` — название (минимум 3 символа)
- `description` — краткое описание применения
- `body` — текст шаблона с переменными
- `toolSlugs` — список инструментов, для которых подходит шаблон (например, `chatgpt`, `midjourney`)
- `categoryId` — опциональная ссылка на категорию
- `variables` — массив переменных (имена без фигурных скобок)

### Синтаксис переменных

- Основной бриф автоматически подставляется в `{{brief}}`.
- Дополнительные переменные задаются в `variables` и используются как `{{variableName}}`.
- Если значение не передано, в итоговом тексте остаётся плейсхолдер `[[VARIABLE]]` — полезно как чек-лист.

Пример `body`:

```
Ты — маркетолог мирового уровня.
Цель: {{brief}}
Целевая аудитория: {{audience}}
Формат ответа: структурированный план из 5 пунктов.
```

`variables = ["audience"]`.

## Управление в UI

1. **Раздел «Шаблоны»** показывает seed-шаблоны и пользовательские. Можно выбрать любой и отредактировать.
2. **TemplateEditor** позволяет:
   - выбрать связанные инструменты (клик по чипам)
   - назначить категорию
   - добавлять/удалять переменные (клик по бейджу удаляет)
   - редактировать текст и описание
3. **Удаление** доступно только для пользовательских шаблонов (seed-шаблоны недоступны для удаления).

## Импорт и экспорт

- **Экспорт** (кнопка «Экспорт шаблонов» в настройках) возвращает массив объектов:

```json
[
  {
    "title": "Маркетинговый контент-план",
    "description": "Структурирует идеи для постов",
    "body": "...",
    "toolSlugs": ["chatgpt", "claude"],
    "categoryId": "clxyz...", // может быть null
    "variables": []
  }
]
```

- **Импорт** ожидает объект `{ "templates": Template[] }`. Валидация Zod проверяет обязательные поля.
- После импорта записи сохраняются под текущим пользователем.

## Программная генерация

При вызове `/api/generate` можно указать `templateId`. Если не передан, система ищет шаблон по инструменту/категории и подставляет бриф.

`renderTemplate` (`src/lib/templates.ts`) отвечает за замену переменных и fallback-значения.

## Рекомендации

- Держите шаблоны максимально конкретными: перечисляйте формат ответа, желаемый стиль, ограничение по объёму.
- Используйте переменные как чек-лист (например, `audience`, `tone`, `output_format`).
- Для Midjourney/DALL·E описывайте сцену одной строкой — стратеги инструмента ожидают линейный промпт.
- Экспортируйте шаблоны перед крупными изменениями — JSON пригодится для бэкапа или шеринга.
